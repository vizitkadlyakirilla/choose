# Кирилл Буланов — сайт-компьютер BulanOS

Финальный сайт-визитка Кирилла Буланова (режиссёр, сценарист, AI-креатор) на основе утверждённой концепции № 2.
Готовая **статическая сборка**: ничего не нужно устанавливать или собирать. Работает на GitHub Pages.

## Что внутри

```
index.html               — сайт (одна страница)
css/os.css               — интерфейс BulanOS, мобильная версия
js/core.js               — настройки (localStorage), звуки (WebAudio), видео-утилиты
js/os.js                 — окна, меню «Пуск», панель задач, уведомления, загрузка/перезагрузка/выключение
js/apps.js               — приложения: Об авторе, Режиссура, Проект (плеер), Сценарии, AI, Фотографии, Контакты, Настройки
js/browser.js            — BulanNet Explorer: вкладки, история, адресная строка, страницы, запуск игр
js/games/engine.js       — мини-движок пиксельных игр на Canvas
js/games/bulanozavr.js   — игра «Буланозавр»
js/games/turnik.js       — игра «Кирилл на турнике»
js/data.js               — контакты и каталог работ (единый источник)
assets/photos/           — фотографии Кирилла (портрет, аватар, турник)
assets/posters/          — кадры из работ
assets/videos/           — видео + manifest.js (см. «Видео»)
tools/prepare_videos.py  — нарезка и оптимизация видео (ffmpeg)
.nojekyll                — отключает Jekyll на GitHub Pages
```

## Публикация на GitHub Pages

1. На github.com: **New repository** → например `bulanov` → **Create repository**.
2. **Add file → Upload files** → перетащите **содержимое** этой папки (чтобы `index.html` был в корне) → **Commit changes**.
3. **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/bulanov/`.
   Все пути относительные, поэтому сайт работает и в подпапке репозитория.
   Свой домен подключается там же (Settings → Pages → Custom domain).

Через git:
```bash
git init && git add . && git commit -m "Сайт Кирилла Буланова"
git branch -M main && git remote add origin https://github.com/<логин>/bulanov.git && git push -u origin main
```

## Что умеет сайт

- **Загрузка BulanOS**: BIOS-экран и логотип. При первом визите — полная, дальше — быстрая. Кнопка «Пропустить загрузку».
- **Рабочий стол**: иконки, окна (открыть, свернуть, развернуть, закрыть, перетащить, изменить размер за угол,
  двойной клик по заголовку — развернуть), панель задач с активным окном, часы, кнопка звука, системные уведомления.
- **Меню «Пуск»**: Об авторе, Режиссёрские работы, Сценарии, AI-проекты, Фотографии, Контакты, Браузер, Игры,
  Настройки, Перезагрузка, Выключение. Управляется и стрелками с клавиатуры.
- **Перезагрузка**: закрывает окна, показывает экран перезагрузки и загрузку, сбрасывает временное состояние.
- **Выключение**: окна закрываются, экран гаснет (эффект старого монитора), появляется кнопка питания.
- **Настройки** (сохраняются в localStorage): звуки, громкость, отключение сложных анимаций, 4 обоя, информация о системе, сброс.
- **Контакты**: кликабельные email, телефон, Telegram, Instagram; копирование; сохранение контакта (.vcf);
  форма «Обсудить проект» — открывает письмо на bulanozavr@mail.ru или чат @bulanozavr (текст копируется заранее).
- **BulanNet Explorer**: вкладки (+ / ×), назад/вперёд, обновить, домой, адресная строка
  (`bulanos://home`, `games`, `bulanozavr`, `turnik`, `works`, `contacts`, `about`). Внешние адреса открываются
  в новой вкладке вашего браузера: встраивать чужие сайты в окно большинство из них запрещает.
- **Игры** (рекорды в localStorage, пауза, заново, звук, выход; автопауза при сворачивании окна, переключении вкладки
  браузера и уходе со страницы):
  - **Буланозавр** — пробел / ↑ / касание; удержание — прыжок выше. Препятствия: штативы, софиты, кассеты, дроны. Скорость растёт.
  - **Кирилл на турнике** — удерживайте (пробел / мышь / палец), чтобы раскачаться, отпустите, чтобы полететь к жёлтой
    перекладине. Уровни каждые 5 перекладин, растут высота и разброс, на первых перекладинах есть подсказка траектории.
    Каждый генерируемый уровень проверен симуляцией — до него всегда можно долететь.
    Пиксельный Кирилл нарисован по фото: волосы с чёлкой, борода, тёмный свитер, джинсы, часы, светлые кроссовки;
    позы — висит, раскачивается (ноги отстают/выносятся вперёд), группируется, отпускает, тянется к перекладине, падает.
- **Мобильная версия**: окна на весь экран, крупные иконки сеткой, меню на всю ширину, сенсорное управление в играх.

## Видео

Плееры настоящие (превью без звука с автозапуском, полный просмотр со звуком, перемотка, громкость, «на весь экран»;
фоновое превью встаёт на паузу при открытии ролика). Источники видео берутся **только** из `assets/videos/manifest.js`,
поэтому битых ссылок не бывает: пока манифест пуст, показываются кадры с пометкой и ссылка на оригинал.

Чтобы видео появились:
1. Скачайте исходники с Яндекс Диска в одну папку (имена файлов — как на Диске, список в `MAP` внутри `tools/prepare_videos.py`).
2. `python3 tools/prepare_videos.py /путь/к/исходникам` (нужен ffmpeg).
3. Скрипт сам выберет выразительный фрагмент ~7 с и сделает превью 1280 и 640 px, полную версию со звуком
   (для роликов до 3 минут и меньше 95 МБ — лимит GitHub 100 МБ на файл), постер и манифест.
4. Закоммитьте `assets/`.

Длинные работы («Петля» — 30 минут, «История одной смерти») на GitHub целиком не поместятся: для них на сайте будет
превью, а полную версию лучше разместить на видеохостинге (Kinescope, VK Видео, Rutube, Vimeo) — выбор за автором.
