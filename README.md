# Кирилл — выбираем стиль сайта

Интерактивная презентация шести концепций сайта-портфолио Кирилла (режиссёр, сценарист, AI-креатор).
Это готовый **статический сайт**: ничего собирать и устанавливать не нужно. Подходит для GitHub Pages.

## Что внутри

```
index.html                 — главная страница презентации (галерея, выбор, сводка оценок)
concepts/concept-01/       — 1. «Кирилл снимает…» (авторский минимализм)
concepts/concept-02/       — 2. «Кирилл.narod» (Experimental Web 2000)
concepts/concept-03/       — 3. «КИРИЛЛ ТВ» (сайт-телеканал)
concepts/concept-04/       — 4. «Кино по скроллу» (Experimental Cinema)
concepts/concept-05/       — 5. «Плакат» (Digital Art Direction)
concepts/concept-06/       — 6. «Лайтбокс» (Creative Wildcard)
assets/posters/            — кадры из работ Кирилла (превью с Яндекс Диска)
assets/videos/             — сюда класть видеофайлы (см. ниже)
assets/fonts/, assets/images/ — зарезервировано
css/present.css            — панель презентации и окно отзыва (общие)
css/index.css              — стили главной страницы
js/data.js                 — каталог работ (единый для всех концепций)
js/config.js               — контакты получателя отзывов
js/common.js               — общие функции (появление при скролле, отправка, модалки)
js/present.js              — панель презентации на каждой концепции + окно «Этот вариант тебе нравится?»
js/index.js                — логика главной страницы
tools/prepare_videos.py    — нарезка и оптимизация видео (ffmpeg) + манифест
archive/iteration-1/       — предыдущие версии вариантов 4–6 (архив, в презентацию не входят)
.nojekyll                  — отключает обработку Jekyll на GitHub Pages
```

Каждая страница концепции открывается отдельно (например `concepts/concept-04/index.html`).
Все пути относительные, поэтому сайт работает по адресу с подпапкой репозитория
(`https://<логин>.github.io/<репозиторий>/`), а также просто при открытии файла с диска.

## Как опубликовать на GitHub Pages

**Вариант без командной строки**

1. На GitHub: **New repository** → имя, например `kirill-portfolio-presentation` → **Create repository**.
2. На странице репозитория: **Add file → Upload files**. Перетащите **содержимое** этой папки
   (файл `index.html` должен оказаться в корне репозитория, а не во вложенной папке) → **Commit changes**.
   Файл `.nojekyll` скрытый: если система его не показывает, ничего страшного — сайт работает и без него.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/kirill-portfolio-presentation/`.

**Через git**

```bash
cd kirill-portfolio-presentation
git init && git add . && git commit -m "Презентация концепций"
git branch -M main
git remote add origin https://github.com/<логин>/kirill-portfolio-presentation.git
git push -u origin main
```
Затем включите Pages, как в шаге 3.

> Если репозиторий публичный, ссылку сможет открыть любой, кто её знает. На странице стоит `noindex`,
> чтобы она не попадала в поиск. Приватные репозитории публикуются в Pages только на платных тарифах GitHub.

## Как работает выбор и отзывы

- На каждой концепции слева есть вкладка **«Варианты»**: переход к списку, предыдущий/следующий вариант,
  **«Выбрать этот вариант»**, **«Оставить замечание»**, **«Скрыть»** (вернуть — синяя точка в левом нижнем углу).
- Окно отзыва: выбранная концепция, оценки 1–5 по пяти критериям, «Что понравилось», «Что изменить», комментарии.
- **Отзыв никуда не отправляется сам** — у GitHub Pages нет сервера. Кнопки:
  - «Отправить в Telegram» — открывает Telegram с готовым текстом (вы выбираете чат и нажимаете «Отправить»);
  - «Скопировать текст» — копирует отзыв в буфер обмена;
  - «Письмом» — открывает почтовый клиент с готовым письмом.
- Черновики и оценки сохраняются в браузере (localStorage). На главной есть сводка и кнопка «Отправить все отзывы».

### Указать реальные контакты

Откройте `js/config.js` и заполните:

```js
window.KP_CONFIG = { telegramUser: 'username_bez_sobaki', email: 'name@example.com' };
```

С указанным `telegramUser` кнопка Telegram копирует текст и открывает чат с этим человеком
(Telegram не позволяет вставить текст в личный чат по ссылке — его нужно вставить вручную).
С указанным `email` письмо сразу адресовано получателю. Те же кнопки работают в контактных формах всех концепций.

## Видео

Плееры во всех концепциях уже настоящие: фоновые превью (`autoplay muted loop playsinline`, пауза вне экрана
и при открытом плеере, кнопка запуска, если браузер запретил автовоспроизведение), полный просмотр со звуком,
перемоткой, громкостью и полноэкранным режимом. Источники видео сайт берёт **только** из `assets/videos/manifest.js`,
поэтому битых ссылок на странице не бывает: пока манифест пуст, показываются кадры и ссылки на оригиналы.

**Чтобы видео появились:**
1. Скачайте исходники с Яндекс Диска в одну папку (имена файлов — как на Диске; список в `tools/prepare_videos.py`, словарь `MAP`).
2. Выполните (нужен ffmpeg): `python3 tools/prepare_videos.py /путь/к/исходникам`
3. Скрипт для каждого ролика сам найдёт выразительный фрагмент ~7 с (по движению в кадре, без первой секунды
   и финального пэкшота) и сделает:
   - `assets/videos/<id>-preview.mp4` — 1280px, H.264, без звука (фон);
   - `assets/videos/<id>-preview-640.mp4` — версия для телефонов;
   - `assets/videos/<id>-full.mp4` — полная версия со звуком (для роликов до 3 минут и файлов меньше 95 МБ);
   - `assets/posters/<id>.jpg` — постер из выбранного фрагмента;
   - `assets/videos/manifest.js`.
   Начало фрагмента можно задать вручную вторым значением в `MAP`.
4. Закоммитьте `assets/` в репозиторий.

**Ограничения GitHub:** файл до 100 МБ (жёстко), репозиторий желательно до 1 ГБ, сайт Pages — до 1 ГБ.
Превью весят около 0,5–1,5 МБ, полные рекламные ролики — 2–15 МБ. Это нормально для Pages.
Длинные работы («Петля» — 30 минут, «История одной смерти», полные версии больше 3 минут) на GitHub не помещаются.
Для них на сайте остаётся превью, а полную версию нужно залить на видеохостинг с прямым или встраиваемым
воспроизведением. Варианты: Kinescope или VK Видео/Rutube (удобны для аудитории в России), Vimeo,
Cloudflare Stream или Mux (HLS), либо прямые MP4 в Yandex Object Storage или Cloudflare R2. Выбор — за заказчиком, у сервисов разная стоимость.
Временные ссылки Яндекс Диска для воспроизведения не используются.

## Шрифты

Шрифты подключаются с Google Fonts (нужен интернет). Без интернета страницы работают
со системными шрифтами — вёрстка не ломается, но выглядит проще. Все шрифты — со свободной лицензией (OFL).

## Демо-ограничения (честно)

- Разделы **«Сценарии»** и **«AI»** во всех концепциях — структура с пометкой «ждём материалы»: материалов пока нет.
- Роль Кирилла, описания и годы производства не подтверждены; в карточках указан год загрузки на Диск.
- Контакты Кирилла не указаны — см. `js/config.js`.
- Второй ролик AliExpress («товары для взрослых») не показан до решения заказчика.
